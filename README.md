# RZ Agent downloads

The Android app that runs your tasks on a device (MuMu, later cloud phones) for the RZ app. This repository holds only the
installable files, as release downloads. The RZ app (Settings, "RZ Agent app") links to the latest one.

- Latest: https://github.com/vince-ck/rz-agent-releases/releases/latest/download/rz-agent.apk
- Each release is a signed APK (`rz-agent.apk`); a newer version installs over an older one.
